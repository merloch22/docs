---
title: 'Editada'
description: 'Mensagem editada.'
---

Disparado quando uma mensagem já enviada é **editada**.

<Info>
Todo webhook também inclui os [campos comuns](/webhook-reference/introducao) — `tipo`, `nome`, `remetente`, `destinatario`, `idMessagem`, `data` e `horario`.
</Info>

## Campos deste evento

<ResponseField name="tipoMensagem" type="string">
  `editedMessage`
</ResponseField>
<ResponseField name="mensagem" type="string">
  Novo conteúdo (após a edição).
</ResponseField>
<ResponseField name="idMessagemInteragida" type="string">
  ID da mensagem que foi editada.
</ResponseField>
<ResponseField name="evento" type="string">
  Sempre `editada`.
</ResponseField>

## Exemplo de payload

```json
{
  "tipo": "Chat",
  "nome": "Diogo Silva",
  "remetente": "5581999999999",
  "destinatario": "5511999999999",
  "idMessagem": "3F53E99E6E00E915EF8C",
  "data": "10/07/2026",
  "horario": "18:00:00",
  "tipoMensagem": "editedMessage",
  "mensagem": "Texto corrigido",
  "evento": "editada",
  "idMessagemInteragida": "3EB0C87FA16F99040DD839"
}
```
