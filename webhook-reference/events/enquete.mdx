Disparado quando uma **enquete** é criada.

<Info>
Todo webhook também inclui os [campos comuns](/webhook-reference/introducao) — `tipo`, `nome`, `remetente`, `destinatario`, `idMessagem`, `data` e `horario`.
</Info>

## Campos deste evento

<ResponseField name="tipoMensagem" type="string">
  `pollCreationMessage`
</ResponseField>
<ResponseField name="mensagem" type="object">
  Objeto da enquete (nome e opções).
</ResponseField>

## Exemplo de payload

```json
{
  "tipo": "Chat",
  "nome": "Diogo Silva",
  "remetente": "5581999999999",
  "destinatario": "5511999999999",
  "idMessagem": "3F53E99E6E00E915EF8C",
  "data": "10/07/2026",
  "horario": "18:00:00",
  "tipoMensagem": "pollCreationMessage",
  "evento": "enquete",
  "mensagem": {
    "name": "Qual o melhor horário?",
    "options": [
      {
        "optionName": "Manhã"
      },
      {
        "optionName": "Tarde"
      }
    ]
  }
}
```
