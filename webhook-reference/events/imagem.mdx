---
title: 'Imagem'
description: 'Imagem enviada ou recebida.'
---

Disparado quando uma **imagem** é enviada ou recebida. O arquivo vem em base64.

<Info>
Todo webhook também inclui os [campos comuns](/webhook-reference/introducao) — `tipo`, `nome`, `remetente`, `destinatario`, `idMessagem`, `data` e `horario`.
</Info>

## Campos deste evento

<ResponseField name="tipoMensagem" type="string">
  `imageMessage`
</ResponseField>
<ResponseField name="mensagem" type="string">
  Legenda da imagem, se houver.
</ResponseField>
<ResponseField name="formato" type="string">
  MIME type do arquivo, ex.: `image/jpeg`.
</ResponseField>
<ResponseField name="arquivo" type="string">
  Conteúdo do arquivo em **base64**.
</ResponseField>
<ResponseField name="filename" type="string">
  Nome do arquivo, quando disponível.
</ResponseField>

## Exemplo de payload

```json
{
  "tipo": "Chat",
  "nome": "Diogo Silva",
  "remetente": "5581999999999",
  "destinatario": "5511999999999",
  "idMessagem": "3F53E99E6E00E915EF8C",
  "data": "10/07/2026",
  "horario": "18:00:00",
  "tipoMensagem": "imageMessage",
  "mensagem": "Olha essa foto!",
  "evento": "multimidia",
  "formato": "image/jpeg",
  "arquivo": "/9j/4AAQSkZJRgABAQAAAQ... (base64)",
  "filename": ""
}
```
