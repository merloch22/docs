---
title: 'Documento'
description: 'Documento (PDF, DOCX, etc.).'
---

Disparado quando um **documento** é enviado ou recebido.

<Info>
Todo webhook também inclui os [campos comuns](/webhook-reference/introducao) — `tipo`, `nome`, `remetente`, `destinatario`, `idMessagem`, `data` e `horario`.
</Info>

## Campos deste evento

<ResponseField name="tipoMensagem" type="string">
  `documentMessage`
</ResponseField>
<ResponseField name="mensagem" type="string">
  Legenda do documento, se houver.
</ResponseField>
<ResponseField name="formato" type="string">
  MIME type, ex.: `application/pdf`.
</ResponseField>
<ResponseField name="arquivo" type="string">
  Conteúdo do arquivo em **base64**.
</ResponseField>
<ResponseField name="filename" type="string">
  Nome original do arquivo.
</ResponseField>

## Exemplo de payload

```json
{
  "tipo": "Chat",
  "nome": "Diogo Silva",
  "remetente": "5581999999999",
  "destinatario": "5511999999999",
  "idMessagem": "3F53E99E6E00E915EF8C",
  "data": "10/07/2026",
  "horario": "18:00:00",
  "tipoMensagem": "documentMessage",
  "mensagem": "",
  "evento": "multimidia",
  "formato": "application/pdf",
  "arquivo": "JVBERi0xLjcKJ... (base64)",
  "filename": "contrato.pdf"
}
```
