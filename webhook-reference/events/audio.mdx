---
title: 'Áudio'
description: 'Áudio ou mensagem de voz.'
---

Disparado quando um **áudio** (ou mensagem de voz) é enviado ou recebido.

<Info>
Todo webhook também inclui os [campos comuns](/webhook-reference/introducao) — `tipo`, `nome`, `remetente`, `destinatario`, `idMessagem`, `data` e `horario`.
</Info>

## Campos deste evento

<ResponseField name="tipoMensagem" type="string">
  `audioMessage`
</ResponseField>
<ResponseField name="formato" type="string">
  MIME type, ex.: `audio/ogg; codecs=opus`.
</ResponseField>
<ResponseField name="arquivo" type="string">
  Conteúdo do áudio em **base64**.
</ResponseField>

## Exemplo de payload

```json
{
  "tipo": "Chat",
  "nome": "Diogo Silva",
  "remetente": "5581999999999",
  "destinatario": "5511999999999",
  "idMessagem": "3F53E99E6E00E915EF8C",
  "data": "10/07/2026",
  "horario": "18:00:00",
  "tipoMensagem": "audioMessage",
  "evento": "multimidia",
  "formato": "audio/ogg; codecs=opus",
  "arquivo": "T2dnUwACAAAAAAAA... (base64)",
  "filename": ""
}
```
