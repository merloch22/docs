---
title: 'Texto'
description: 'Mensagem de texto enviada ou recebida.'
---

Disparado quando uma mensagem de **texto** é enviada ou recebida.

<Info>
Todo webhook também inclui os [campos comuns](/webhook-reference/introducao) — `tipo`, `nome`, `remetente`, `destinatario`, `idMessagem`, `data` e `horario`.
</Info>

## Campos deste evento

<ResponseField name="tipoMensagem" type="string">
  `conversation` ou `extendedTextMessage`
</ResponseField>
<ResponseField name="mensagem" type="string">
  Conteúdo do texto.
</ResponseField>

## Exemplo de payload

```json
{
  "tipo": "Chat",
  "nome": "Diogo Silva",
  "remetente": "5581999999999",
  "destinatario": "5511999999999",
  "idMessagem": "3F53E99E6E00E915EF8C",
  "data": "10/07/2026",
  "horario": "18:00:00",
  "tipoMensagem": "extendedTextMessage",
  "mensagem": "Oi, tudo bem?",
  "evento": "texto"
}
```
