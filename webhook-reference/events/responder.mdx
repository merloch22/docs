---
title: 'Responder'
description: 'Resposta citando outra mensagem.'
---

Disparado quando uma mensagem é enviada **respondendo (citando)** outra.

<Info>
Todo webhook também inclui os [campos comuns](/webhook-reference/introducao) — `tipo`, `nome`, `remetente`, `destinatario`, `idMessagem`, `data` e `horario`.
</Info>

## Campos deste evento

<ResponseField name="tipoMensagem" type="string">
  `extendedTextMessage` (ou o tipo da mídia respondida)
</ResponseField>
<ResponseField name="mensagem" type="string">
  Conteúdo da resposta.
</ResponseField>
<ResponseField name="idMessagemInteragida" type="string">
  ID da mensagem original que foi respondida.
</ResponseField>
<ResponseField name="evento" type="string">
  Sempre `respondida`.
</ResponseField>

## Exemplo de payload

```json
{
  "tipo": "Chat",
  "nome": "Diogo Silva",
  "remetente": "5581999999999",
  "destinatario": "5511999999999",
  "idMessagem": "3F53E99E6E00E915EF8C",
  "data": "10/07/2026",
  "horario": "18:00:00",
  "tipoMensagem": "extendedTextMessage",
  "mensagem": "Sem problemas!",
  "evento": "respondida",
  "idMessagemInteragida": "BAE508EF2263A826"
}
```
