---
title: 'Reação'
description: 'Reação (emoji) a uma mensagem.'
---

Disparado quando alguém **reage** a uma mensagem com um emoji.

<Info>
Todo webhook também inclui os [campos comuns](/webhook-reference/introducao) — `tipo`, `nome`, `remetente`, `destinatario`, `idMessagem`, `data` e `horario`.
</Info>

## Campos deste evento

<ResponseField name="tipoMensagem" type="string">
  `reactionMessage`
</ResponseField>
<ResponseField name="emojiReacao" type="string">
  Emoji da reação (vazio quando a reação é removida).
</ResponseField>
<ResponseField name="idMessagemInteragida" type="string">
  ID da mensagem que recebeu a reação.
</ResponseField>
<ResponseField name="evento" type="string">
  Sempre `reagida`.
</ResponseField>

## Exemplo de payload

```json
{
  "tipo": "Chat",
  "nome": "Diogo Silva",
  "remetente": "5581999999999",
  "destinatario": "5511999999999",
  "idMessagem": "3F53E99E6E00E915EF8C",
  "data": "10/07/2026",
  "horario": "18:00:00",
  "tipoMensagem": "reactionMessage",
  "evento": "reagida",
  "emojiReacao": "❤️",
  "idMessagemInteragida": "BAE508EF2263A826"
}
```
