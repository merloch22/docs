---
title: 'Contato'
description: 'Cartão de contato (vCard).'
---

Disparado quando um **contato** é compartilhado.

<Info>
Todo webhook também inclui os [campos comuns](/webhook-reference/introducao) — `tipo`, `nome`, `remetente`, `destinatario`, `idMessagem`, `data` e `horario`.
</Info>

## Campos deste evento

<ResponseField name="tipoMensagem" type="string">
  `contactMessage`
</ResponseField>
<ResponseField name="mensagem" type="string">
  Nome de exibição do contato.
</ResponseField>
<ResponseField name="Contato" type="object">
  Objeto com `Nome` e `Fone` do contato.
</ResponseField>

## Exemplo de payload

```json
{
  "tipo": "Chat",
  "nome": "Diogo Silva",
  "remetente": "5581999999999",
  "destinatario": "5511999999999",
  "idMessagem": "3F53E99E6E00E915EF8C",
  "data": "10/07/2026",
  "horario": "18:00:00",
  "tipoMensagem": "contactMessage",
  "mensagem": "Maria Souza",
  "evento": "contato",
  "Contato": {
    "Nome": "Maria Souza",
    "Fone": "5581988887777"
  }
}
```
