## Envie em segundos

Já tem sua `appkey` e `authkey`? Este é um envio de texto completo:

<CodeGroup>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/create-message \
  -H "Content-Type: application/json" \
  -d '{
    "appkey": "SEU_APPKEY",
    "authkey": "SUA_AUTHKEY",
    "to": "5581999999999",
    "message": "Olá! 👋 Mensagem enviada pela API da Menuia."
  }'
```

```javascript Node.js
await fetch("https://chatbot.menuia.com/api/create-message", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    appkey: "SEU_APPKEY",
    authkey: "SUA_AUTHKEY",
    to: "5581999999999",
    message: "Olá! 👋 Mensagem enviada pela API da Menuia."
  })
});
```

```python Python
import requests

requests.post("https://chatbot.menuia.com/api/create-message", json={
    "appkey": "SEU_APPKEY",
    "authkey": "SUA_AUTHKEY",
    "to": "5581999999999",
    "message": "Olá! 👋 Mensagem enviada pela API da Menuia."
})
```

```php PHP
Http::post("https://chatbot.menuia.com/api/create-message", [
    "appkey"  => "SEU_APPKEY",
    "authkey" => "SUA_AUTHKEY",
    "to"      => "5581999999999",
    "message" => "Olá! 👋 Mensagem enviada pela API da Menuia.",
]);
```
</CodeGroup>

<Note>
Não tem as chaves ainda? Veja [Endpoints e Tokens](/pages/endpoints/introducao) para gerar sua `authkey` e `appkey`.
