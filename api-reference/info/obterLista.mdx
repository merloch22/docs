---

## Descricao

Este endpoint permite obter a lista de planos disponiveis no sistema. A resposta inclui informacoes sobre os planos, como o nome do plano, preco, descricao e outras caracteristicas associadas.

### Parametros

<ParamField body="planos" type="string" required>
  Deve ser definido como "true" para obter a lista de planos.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/info \
  -H "Content-Type: application/json" \
  -d '{
    "planos": "true"
  }'
```

```javascript Node.js
const response = await fetch('https://chatbot.menuia.com/api/info', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    planos: 'true'
  })
});
```

```python Python
import requests

response = requests.post(
    'https://chatbot.menuia.com/api/info',
    json={
        'planos': 'true'
    }
)
```

```php PHP
$response = Http::post('https://chatbot.menuia.com/api/info', [
    'planos' => 'true'
]);
```
</RequestExample>
