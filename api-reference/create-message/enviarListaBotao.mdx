## Descrição

Este endpoint permite enviar uma mensagem interativa com lista de opções organizadas em seções. Ideal para menus de serviços, catálogos de produtos ou qualquer situação que necessite de múltiplas escolhas organizadas.

<Info>
  **Compatibilidade:** a lista é exibida no **iPhone (iOS)** e no **Android**. Ela aparece como um card com imagem no topo e um botão que abre as opções. No **WhatsApp Web** mensagens interativas não são renderizadas.
</Info>

<Note>
  **Resposta da seleção:** quando o usuário escolhe uma opção, o webhook **Botão / Lista** recebe a escolha normalmente (id e texto), e o painel exibe a opção selecionada. Por uma limitação do próprio WhatsApp, a *bolha* dessa resposta pode não ser exibida para quem acompanha a conversa pelo **aplicativo** do WhatsApp (o outro aparelho vê "atualize o WhatsApp"). Isso é apenas visual e **não afeta** o recebimento pelo webhook nem o acompanhamento pelo painel.
</Note>

### Parâmetros

<ParamField body="appkey" type="string" required>
  Chave de aplicação.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="to" type="string" required>
  Número de telefone no formato internacional ou ID do grupo.
</ParamField>

<ParamField body="message" type="string" required>
  Texto principal da mensagem que aparece antes da lista.
</ParamField>

<ParamField body="header_title" type="string">
  Título exibido no card da lista. Se omitido, é usado "Menu". *(opcional — personalização)*
</ParamField>

<ParamField body="header_image" type="string">
  URL de uma imagem para o topo do card da lista. Se omitido, é usada uma imagem padrão. *(opcional — personalização)*
</ParamField>

<ParamField body="footer_text" type="string">
  Texto do rodapé da lista. *(opcional — personalização)*
</ParamField>

<ParamField body="button_text" type="string" required>
  Texto do botão que abre a lista de opções.
</ParamField>

<ParamField body="section" type="array" required>
  Array de seções contendo as opções da lista. Cada seção possui:
  - `title`: Título da seção
  - `value`: Array de itens com `title` e `description` (a `description` é opcional)

  Suporta várias seções e um número alto de opções (testado com 24 renderizando normalmente). Para uma boa experiência, mantenha a quantidade de opções razoável.
</ParamField>
