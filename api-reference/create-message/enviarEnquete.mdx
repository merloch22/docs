## Descrição

Este endpoint envia uma **enquete** (poll) interativa. O destinatário vê a pergunta e as
alternativas e pode votar diretamente no chat. Ideal para pesquisas rápidas, votações e
coleta de preferências.

<Info>
  O **resultado dos votos** é agregado nativamente pelo WhatsApp e fica visível no aplicativo
  de quem enviou a enquete. A leitura **programática** dos votos (webhook de voto) ainda não
  está disponível — os votos chegam criptografados e o recurso de descriptografia está no
  roadmap.
</Info>

### Parâmetros

<ParamField body="appkey" type="string" required>
  Chave de aplicação.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="to" type="string" required>
  Número de telefone no formato internacional ou ID do grupo.
</ParamField>

<ParamField body="message" type="string" required>
  A **pergunta** da enquete (o texto que aparece no topo).
</ParamField>

<ParamField body="opcoes" type="array" required>
  Array de textos com as alternativas. Mínimo de **2** e máximo de **12** opções. Não pode
  haver opções repetidas.
</ParamField>

<ParamField body="multiplaEscolha" type="boolean" default="false">
  Quando `true`, o destinatário pode marcar **mais de uma** opção. Quando `false` (padrão),
  a enquete permite apenas **uma** escolha.
</ParamField>

  }'
