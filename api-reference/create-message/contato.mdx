---

## Descrição

Este endpoint permite enviar um contato, incluindo o nome e número de telefone, para um número ou grupo.

### Parâmetros

<ParamField body="appkey" type="string" required>
  Chave de aplicação.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="to" type="string" required>
  Número de telefone no formato internacional ou ID do grupo.
</ParamField>

<ParamField body="message" type="string" required>
  Número do contato a ser enviado.
</ParamField>

<ParamField body="contact" type="string" required>
  Nome do contato a ser enviado.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/create-message \
  -H "Content-Type: application/json" \
  -d '{

    "authkey": "SUA_AUTHKEY_AQUI",
    "to": "+5581989769960",
    "message": "+5581999999999",
    "contact": "Nome do Contato"
  }'
```
