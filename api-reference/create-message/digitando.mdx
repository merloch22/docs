## Descrição

Envia o indicador de **"digitando…"** (ou **"gravando áudio…"**) para um contato, deixando o atendimento mais natural e humano. O indicador some sozinho após alguns segundos, ao enviar a próxima mensagem, ou quando você envia o estado `paused`.

### Parâmetros

<ParamField body="appkey" type="string" required>
  Chave de aplicação.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="to" type="string" required>
  Número do destinatário, com DDI e DDD.
</ParamField>

<ParamField body="presence" type="string" required>
  Estado a exibir:
  - `composing` — "digitando…"
  - `recording` — "gravando áudio…"
  - `paused` — parar o indicador
</ParamField>
