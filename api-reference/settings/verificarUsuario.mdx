title: 'Verificar se o Contato Está no WhatsApp'
api: 'POST https://chatbot.menuia.com/api/settings'
---

## Descrição

Este endpoint permite verificar se um número de telefone está registrado no WhatsApp. A operação é ativada pelo parâmetro `checkDevice`.

### Parâmetros

<ParamField body="appkey" type="string" required>
  Chave da aplicação.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="message" type="string" required>
  Deve ser `"false"` para realizar a operação.
</ParamField>

<ParamField body="checkDevice" type="string" required>
  Número de telefone a ser verificado (exemplo: `5581989769960`).
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/settings \
  -H "Content-Type: application/json" \
  -d '{
    "appkey": "SUA_APPKEY_AQUI",
    "authkey": "SUA_AUTHKEY_AQUI",
    "message": "false",
    "checkDevice": "5581989769960"
  }'
```

```javascript Node.js
const response = await fetch('https://chatbot.menuia.com/api/settings', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    appkey: 'SUA_APPKEY_AQUI',
    authkey: 'SUA_AUTHKEY_AQUI',
    message: 'false',
    checkDevice: '5581989769960'
  })
});
```

```python Python
import requests

response = requests.post(
    'https://chatbot.menuia.com/api/settings',

        'authkey': 'SUA_AUTHKEY_AQUI',
        'message': 'false',

    }
)
```

```php PHP
$response = Http::post('https://chatbot.menuia.com/api/settings', [
    'appkey' => 'SUA_APPKEY_AQUI',

```
</RequestExample>

<ResponseExample>
```json 200 - Sucesso (Usuário existe)
{
  "status": 200,
  "message": "Usuário encontrado no WhatsApp.",
  "exists": true
}
```

```json 200 - Sucesso (Usuário não existe)
{
  "status": 200,
  "message": "Usuário não encontrado no WhatsApp.",
  "exists": false
}
```

```json 401 - Erro de validação
{
  "status": 401,
  "message": "validation.required"
}
```

```json 404 - Dispositivo não encontrado
{
  "status": 404,
  "message": "Nenhum dispositivo encontrado."
}
```
</ResponseExample>
