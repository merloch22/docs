---
title: 'Pausar ou Iniciar Conversa Chatbot (Fluxo)'
api: 'POST https://chatbot.menuia.com/api/settings'
---

## Descrição

Este endpoint permite pausar ou iniciar fluxos de conversa no chatbot, com base no status informado no parâmetro `statusFluxo`.

### Parâmetros

<ParamField body="appkey" type="string" required>
  Chave da aplicação.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="to" type="string" required>
  Número de telefone do destinatário.
</ParamField>

<ParamField body="message" type="string" required>
  Valor obrigatório para indicar o conteúdo da mensagem. Para essa operação, deve ser `"false"`.
</ParamField>

<ParamField body="statusFluxo" type="string" required>
  Define o status do fluxo. Use `"Ativar"` para iniciar o fluxo ou `"Desativar"` para pausá-lo.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/settings \
  -H "Content-Type: application/json" \
  -d '{
    "appkey": "SUA_APPKEY_AQUI",
    "authkey": "SUA_AUTHKEY_AQUI",
    "to": "+5581989769960",
    "message": "false",
    "statusFluxo": "Ativar"
  }'
```

```javascript Node.js
const response = await fetch('https://chatbot.menuia.com/api/settings', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    appkey: 'SUA_APPKEY_AQUI',
    authkey: 'SUA_AUTHKEY_AQUI',
    to: '+5581989769960',
    message: 'false',
    statusFluxo: 'Ativar'
  })
});
```

```python Python
import requests

response = requests.post(
    'https://chatbot.menuia.com/api/settings',

        'authkey': 'SUA_AUTHKEY_AQUI',
        'to': '+5581989769960',
        'message': 'false',
        'statusFluxo': 'Ativar'
    }
)
```

```php PHP

    'message' => 'false',
    'statusFluxo' => 'Ativar'

```
</RequestExample>
