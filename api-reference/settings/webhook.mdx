---
title: 'Desativar e Ativar Webhooks'
api: 'POST https://chatbot.menuia.com/api/settings'
---

## Descrição

Este endpoint permite ativar ou desativar webhooks para chats ou grupos no sistema do chatbot. A operação é configurada pelo parâmetro `statusWebhook`.

### Parâmetros

<ParamField body="appkey" type="string" required>
  Chave da aplicação.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="type" type="string" required>
  Define o tipo de webhook, sendo `"chat"` ou `"grupo"`.
</ParamField>

<ParamField body="message" type="string" required>
  ID do dispositivo relacionado ao webhook.
</ParamField>

<ParamField body="statusWebhook" type="string" required>
  Deve ser `"true"` para ativar ou `"false"` para desativar o webhook.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/settings \
  -H "Content-Type: application/json" \
  -d '{
    "appkey": "SUA_APPKEY_AQUI",
    "authkey": "SUA_AUTHKEY_AQUI",
    "type": "chat",
    "message": "ID_DISPOSITIVO_AQUI",
    "statusWebhook": "true"
  }'
```

```javascript Node.js
const response = await fetch('https://chatbot.menuia.com/api/settings', {
```
