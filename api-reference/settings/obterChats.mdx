---
title: 'Obter Lista de Chats'
api: 'POST https://chatbot.menuia.com/api/settings'
---

## Descrição

Este endpoint permite obter a lista de chats disponíveis no sistema do chatbot. A operação é ativada pelo parâmetro `listChat`.

### Parâmetros

<ParamField body="appkey" type="string" required>
  Chave da aplicação.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="message" type="string" required>
  Deve ser `"false"` para realizar a operação.
</ParamField>

<ParamField body="listChat" type="string" required>
  Deve ser `"true"` para solicitar a lista de chats.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/settings \
  -H "Content-Type: application/json" \
  -d '{
    "appkey": "SUA_APPKEY_AQUI",
    "authkey": "SUA_AUTHKEY_AQUI",
    "message": "false",
    "listChat": "true"
  }'
```

```javascript Node.js
const response = await fetch('https://chatbot.menuia.com/api/settings', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    appkey: 'SUA_APPKEY_AQUI',
    authkey: 'SUA_AUTHKEY_AQUI',
    message: 'false',
    listChat: 'true'
  })
});
```

```python Python
import requests

response = requests.post(
    'https://chatbot.menuia.com/api/settings',
    json={
        'appkey': 'SUA_APPKEY_AQUI',
        'authkey': 'SUA_AUTHKEY_AQUI',
        'message': 'false',
        'listChat': 'true'
    }
)
```

```php PHP
$response = Http::post('https://chatbot.menuia.com/api/settings', [
    'appkey' => 'SUA_APPKEY_AQUI',
    'authkey' => 'SUA_AUTHKEY_AQUI',
    'message' => 'false',
    'listChat' => 'true'
]);
```
</RequestExample>

<ResponseExample>
```json 200 - Sucesso
{
  "status": 200,
  "message": "Lista de chats obtida com sucesso.",

}
```

</ResponseExample>
