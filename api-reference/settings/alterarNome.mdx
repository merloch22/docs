## Descrição

Este endpoint permite alterar o nome associado a um fluxo ou configuração do chatbot. A alteração é confirmada pelo parâmetro `altereNome`.

### Parâmetros

<ParamField body="appkey" type="string" required>
  Chave da aplicação.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="message" type="string" required>
  Novo nome a ser atribuído.
</ParamField>

<ParamField body="altereNome" type="string" required>
  Deve ser `"true"` para confirmar a alteração do nome.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/settings \
  -H "Content-Type: application/json" \
  -d '{
    "appkey": "SUA_APPKEY_AQUI",
    "authkey": "SUA_AUTHKEY_AQUI",
    "message": "Novo nome aqui",
    "altereNome": "true"
  }'
```

```javascript Node.js
const response = await fetch('https://chatbot.menuia.com/api/settings', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    appkey: 'SUA_APPKEY_AQUI',
    authkey: 'SUA_AUTHKEY_AQUI',
    message: 'Novo nome aqui',
    altereNome: 'true'
  })
});
```

```python Python
import requests

response = requests.post(
    'https://chatbot.menuia.com/api/settings',
    json={
        'appkey': 'SUA_APPKEY_AQUI',
        'authkey': 'SUA_AUTHKEY_AQUI',
        'message': 'Novo nome aqui',
        'altereNome': 'true'
    }
)
```

```php PHP
$response = Http::post('https://chatbot.menuia.com/api/settings', [
    'appkey' => 'SUA_APPKEY_AQUI',
    'authkey' => 'SUA_AUTHKEY_AQUI',
    'message' => 'Novo nome aqui',
    'altereNome' => 'true'
]);
```
</RequestExample>
