## Descrição

Este endpoint permite obter o status de um usuário específico no sistema do chatbot. A operação é ativada pelo parâmetro `obterStatus`.

### Parâmetros

<ParamField body="appkey" type="string" required>
  Chave da aplicação.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="to" type="string" required>
  Número de telefone do usuário para quem o status será obtido (exemplo: `5511999999999`).
</ParamField>

<ParamField body="message" type="string" required>
  Deve ser `"false"` para realizar a operação.
</ParamField>

<ParamField body="obterStatus" type="string" required>
  Deve ser `"true"` para solicitar o status do usuário.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/settings \
  -H "Content-Type: application/json" \
  -d '{
    "appkey": "SUA_APPKEY_AQUI",
    "authkey": "SUA_AUTHKEY_AQUI",
    "to": "+5511999999999",
    "message": "false",
    "obterStatus": "true"
  }'
```

```javascript Node.js
const response = await fetch('https://chatbot.menuia.com/api/settings', {

});
```
