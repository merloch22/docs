## Descrição

Este endpoint permite obter a imagem de um usuário ou grupo no sistema do chatbot. A operação é ativada pelo parâmetro `obterImagem`.

### Parâmetros

<ParamField body="appkey" type="string" required>
  Chave da aplicação.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="to" type="string" required>
  Número do usuário (ex: `5511999999999`) ou ID do grupo (ex: `120363180117806010@g.us`).
</ParamField>

<ParamField body="obterImagem" type="string" required>
  Deve ser `"true"` para solicitar a imagem.
</ParamField>

<ParamField body="message" type="string" required>
  Deve ser `"false"` para realizar a operação.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/settings \
  -H "Content-Type: application/json" \
  -d '{
    "appkey": "SUA_APPKEY_AQUI",
    "authkey": "SUA_AUTHKEY_AQUI",
    "to": "5511999999999",
    "obterImagem": "true",
    "message": "false"
  }'
```
