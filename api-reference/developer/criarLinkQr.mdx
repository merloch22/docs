---
title: 'Criar Link de Compartilhamento de QRcode'
api: 'POST https://chatbot.menuia.com/api/developer'
---

## Descrição

Este endpoint permite criar um link de compartilhamento de QRcode para um dispositivo, fornecendo o `appkey` ou nome do dispositivo.

### Parâmetros

<ParamField body="appkey" type="string" required>
  O `appkey` ou nome do dispositivo associado ao QRcode.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="message" type="string" required>
  Nome para o dispositivo que gerará o link do QRcode.
</ParamField>

<ParamField body="GerenciarLinks" type="string" required>
  Deve ser "conectar" para criar o link de compartilhamento de QRcode.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/developer \
  -H "Content-Type: application/json" \
  -d '{
    "appkey": "SUA_APPKEY_AQUI",
    "authkey": "SUA_AUTHKEY_AQUI",
    "message": "nome para o dispositivo",
    "GerenciarLinks": "conectar"
  }'
```

```javascript Node.js
const response = await fetch('https://chatbot.menuia.com/api/developer', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    appkey: 'SUA_APPKEY_AQUI',
    authkey: 'SUA_AUTHKEY_AQUI',
    message: 'nome para o dispositivo',

  })
});
```

```python Python
import requests

response = requests.post(
    'https://chatbot.menuia.com/api/developer',

        'appkey': 'SUA_APPKEY_AQUI',
        'authkey': 'SUA_AUTHKEY_AQUI',
        'message': 'nome para o dispositivo',
        'GerenciarLinks': 'conectar'
    }
)
```

```php PHP
$response = Http::post('https://chatbot.menuia.com/api/developer', [

]);
```
</RequestExample>
