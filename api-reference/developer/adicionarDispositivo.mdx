## Descrição

Este endpoint permite adicionar um novo dispositivo ao sistema utilizando um QR Code para autenticação. O dispositivo é identificado por um nome, e pode incluir um webhook opcional para notificações.

### Parâmetros

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="message" type="string" required>
  Nome do dispositivo a ser registrado.
</ParamField>

<ParamField body="conecteQR" type="string" required>
  Deve ser "true" para indicar que a autenticação será feita via QR Code.
</ParamField>

<ParamField body="webhook" type="string">
  URL do webhook para notificações do dispositivo.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/developer \
  -H "Content-Type: application/json" \
  -d '{
    "authkey": "SUA_AUTHKEY_AQUI",
    "message": "Nome do Dispositivo",
    "conecteQR": "true",
    "webhook": "https://exemplo.com/webhook"
  }'
```

```javascript Node.js
const response = await fetch('https://chatbot.menuia.com/api/developer', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    authkey: 'SUA_AUTHKEY_AQUI',
    message: 'Nome do Dispositivo',
    conecteQR: 'true',
    webhook: 'https://exemplo.com/webhook'
  })
});
```

```python Python
import requests

response = requests.post(
    'https://chatbot.menuia.com/api/developer',
    json={
        'authkey': 'SUA_AUTHKEY_AQUI',
        'message': 'Nome do Dispositivo',
        'conecteQR': 'true',
        'webhook': 'https://exemplo.com/webhook'
    }
)
```

```php PHP
$response = Http::post('https://chatbot.menuia.com/api/developer', [
    'authkey' => 'SUA_AUTHKEY_AQUI',

]);
```
</RequestExample>
