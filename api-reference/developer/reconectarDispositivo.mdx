title: 'Reconectar Dispositivo'
api: 'POST https://chatbot.menuia.com/api/developer'
---

## Descrição

Este endpoint permite reconectar um dispositivo usando o link de compartilhamento de QRcode, fornecendo o `appkey` ou nome do dispositivo, além do nome ou ID do dispositivo que será reconectado.

### Parâmetros

<ParamField body="appkey" type="string" required>
  O `appkey` ou nome do dispositivo associado ao QRcode.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="message" type="string" required>
  Nome para o link que será usado para reconectar o dispositivo.
</ParamField>

<ParamField body="to" type="string" required>
  Nome ou ID do dispositivo a ser reconectado.
</ParamField>

<ParamField body="GerenciarLinks" type="string" required>
  Deve ser "reconectar" para realizar a reconexão via link de QRcode.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/developer \
  -H "Content-Type: application/json" \
  -d '{
    "appkey": "SUA_APPKEY_AQUI",
    "authkey": "SUA_AUTHKEY_AQUI",
    "message": "nome para link",
    "to": "Nome ou id do dispositivo",
    "GerenciarLinks": "reconectar"
  }'
```
