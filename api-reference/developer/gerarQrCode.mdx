## Descrição

Este endpoint permite gerar um QR Code ou código de pareamento para conectar um dispositivo WhatsApp. Se o parâmetro `phone` for enviado, será gerado um código de pareamento; caso contrário, será gerado um QR Code tradicional.

### Parâmetros

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="setAppkey" type="string">
  Nome para criar uma appkey automaticamente. Se não informado, será gerada uma appkey aleatória.
</ParamField>

<ParamField body="phone" type="string">
  Número de telefone para gerar código de pareamento. Se não informado, será gerado QR Code.
</ParamField>

<ParamField body="webhook" type="string">
  URL do webhook para receber notificações (opcional).
</ParamField>

<Info>
**Código de Pareamento vs QR Code:**
- Se `phone` for enviado: Gera um código de 8 dígitos para parear via WhatsApp
- Se `phone` não for enviado: Gera um QR Code para escanear com o WhatsApp
</Info>

<RequestExample>
```bash cURL (QR Code)
curl -X POST https://chatbot.menuia.com/api/v2/qrcode \
  -H "Content-Type: application/json" \
  -d '{

    "setAppkey": "meu-dispositivo",
    "webhook": "https://meusite.com/webhook"
  }'
```
