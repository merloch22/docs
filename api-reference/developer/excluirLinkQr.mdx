---
title: 'Excluir Link QR'
api: 'POST https://chatbot.menuia.com/api/developer'
---

## Descrição

Este endpoint permite excluir um link de compartilhamento de QRcode de um dispositivo, fornecendo o `appkey` ou nome do dispositivo, além do nome ou ID do dispositivo cujo link será excluído.

### Parâmetros

<ParamField body="appkey" type="string" required>
  O `appkey` ou nome do dispositivo associado ao QRcode.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="message" type="string" required>
  Deve ser "false" para indicar que o objetivo é excluir o link de QRcode.
</ParamField>

<ParamField body="to" type="string" required>
  Nome ou ID do dispositivo cujo link de QRcode será excluído.
</ParamField>

<ParamField body="GerenciarLinks" type="string" required>
  Deve ser "excluir" para excluir o link de compartilhamento de QRcode.
</ParamField>

<RequestExample>
```bash cURL

    "to": "Nome ou id do dispositivo",

  }'
```
