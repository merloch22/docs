## Descrição

Este endpoint permite definir permissões para um grupo, controlando quem pode enviar mensagens, alterar a imagem do grupo e outras permissões, como se a mensagem é restrita aos administradores ou pode ser enviada por todos.

### Parâmetros

<ParamField body="appkey" type="string" required>
  Chave de aplicação.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="message" type="string" required>
  Tipo de permissão a ser configurada. As opções incluem:
  - `not_announcement`: Todos podem enviar mensagens.
  - `announcement`: Apenas administradores podem enviar mensagens.
  - `unlocked`: Todos podem alterar a imagem do grupo.
  - `locked`: Apenas administradores podem alterar a imagem do grupo.
</ParamField>

<ParamField body="to" type="string" required>
  ID do grupo cuja permissão será alterada.
</ParamField>

<ParamField body="permissaoGrupo" type="string" required>
  Deve ser "true" para ativar a alteração das permissões.
</ParamField>

<RequestExample>

```bash cURL
    "authkey": "SUA_AUTHKEY_AQUI",
    "message": "not_announcement",
    "to": "ID_DO_GRUPO",
    "permissaoGrupo": "true"
  }'
```

```json 200 - Sucesso
{
```
