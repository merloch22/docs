## Descrição

Este endpoint permite criar um novo grupo, especificando o nome do grupo e a lista de usuários que devem ser adicionados.

### Parâmetros

<ParamField body="appkey" type="string" required>
  Chave de aplicação.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="message" type="string" required>
  Nome do grupo que será criado.
</ParamField>

<ParamField body="usuarios" type="string" required>
  Lista de usuários para adicionar ao grupo, separados por hífen (`-`).
</ParamField>

<ParamField body="criarGrupo" type="string" required>
  Deve ser "true" para criar o grupo.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/groups \
  -H "Content-Type: application/json" \
  -d '{
    "appkey": "SUA_APPKEY_AQUI",
    "authkey": "SUA_AUTHKEY_AQUI",
    "message": "Nome do Grupo",
    "usuarios": "5581989769960-55819988775522",
    "criarGrupo": "true"
  }'
```
