title: 'Listar Grupos'
api: 'POST https://chatbot.menuia.com/api/groups'
---

## Descrição

Este endpoint permite obter uma lista de grupos cadastrados, retornando o nome e o ID de cada grupo.

### Parâmetros

<ParamField body="appkey" type="string" required>
  Chave de aplicação.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="message" type="string" required>
  Deve ser "listagrupo" para listar os grupos.
</ParamField>

<ParamField body="grupo" type="string" required>
  Deve ser "true" para ativar a listagem de grupos.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/groups \
  -H "Content-Type: application/json" \
  -d '{
    "appkey": "SUA_APPKEY_AQUI",
    "authkey": "SUA_AUTHKEY_AQUI",
    "message": "listagrupo",
    "grupo": "true"
  }'
```

```javascript Node.js
const response = await fetch('https://chatbot.menuia.com/api/groups', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    appkey: 'SUA_APPKEY_AQUI',
    authkey: 'SUA_AUTHKEY_AQUI',
    message: 'listagrupo',

});
```

```python Python
import requests

```

