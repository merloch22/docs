title: 'Alterar Título do Grupo'
api: 'POST https://chatbot.menuia.com/api/groups'
---

## Descrição

Este endpoint permite alterar o título de um grupo existente, especificando o novo título e o ID do grupo.

### Parâmetros

<ParamField body="appkey" type="string" required>
  Chave de aplicação.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="message" type="string" required>
  Novo título do grupo.
</ParamField>

<ParamField body="to" type="string" required>
  ID do grupo cujo título será alterado.
</ParamField>

<ParamField body="tituloGrupo" type="string" required>
  Deve ser "true" para ativar a alteração de título.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/groups \
  -H "Content-Type: application/json" \
  -d '{
    "appkey": "SUA_APPKEY_AQUI",
    "authkey": "SUA_AUTHKEY_AQUI",
    "message": "Novo Título do Grupo",
    "to": "ID_DO_GRUPO",
    "tituloGrupo": "true"
  }'
```
