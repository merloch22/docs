## Descrição

Este endpoint permite alterar a descrição de um grupo existente, especificando a nova descrição e o ID do grupo.

### Parâmetros

<ParamField body="appkey" type="string" required>
  Chave de aplicação.
</ParamField>

<ParamField body="authkey" type="string" required>
  Chave de autenticação do usuário.
</ParamField>

<ParamField body="message" type="string" required>
  Nova descrição do grupo.
</ParamField>

<ParamField body="to" type="string" required>
  ID do grupo cuja descrição será alterada.
</ParamField>

<ParamField body="descGrupo" type="string" required>
  Deve ser "true" para ativar a alteração de descrição.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/groups \
  -H "Content-Type: application/json" \
  -d '{
    "appkey": "SUA_APPKEY_AQUI",
    "authkey": "SUA_AUTHKEY_AQUI",
    "message": "Nova descrição do grupo",
    "to": "ID_DO_GRUPO",
    "descGrupo": "true"
  }'
```

```javascript Node.js
const response = await fetch('https://chatbot.menuia.com/api/groups', {
```

</RequestExample>
