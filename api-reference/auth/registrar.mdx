## Descricao

Este endpoint permite registrar um novo usuario e obter informacoes como nome, e-mail, telefone, `authkey`, data de expiracao e o plano do usuario.

### Parametros

<ParamField body="email" type="string" required>
  O e-mail do usuario para registro.
</ParamField>

<ParamField body="senha" type="string" required>
  A senha do usuario para registro.
</ParamField>

<ParamField body="nome" type="string" required>
  Nome completo do usuario.
</ParamField>

<ParamField body="telefone" type="string" required>
  Numero de telefone do usuario (incluindo codigo do pais).
</ParamField>

<ParamField body="plano" type="string" required>
  ID do plano do usuario.
</ParamField>

<ParamField body="auth" type="string" required>
  Identificador da requisicao, deve ser "registrar" para registrar um novo usuario.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://chatbot.menuia.com/api/auth \
  -H "Content-Type: application/json" \
  -d '{
    "email": "exemplo@exemplo.com",
    "senha": "SuaSenhaAqui",
    "nome": "Joao",
    "telefone": "+558198976996",
    "plano": "ID_DO_PLANO",
    "auth": "registrar"
  }'
```
